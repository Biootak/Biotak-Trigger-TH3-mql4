# AGENTS.md — Biotak Trigger TH3 (MQL4)

MT4 custom indicator (Prof. Khakestar's TH levels). MQL4 only; Python/PowerShell
in `tools/` are audits and asset generators, never product code.

## Reply language

User speaks Persian. Reply in Persian, answer in the first line, short lines,
proof (file, number, log line) instead of adjectives, concrete test steps at
the end. English only as literal code/screen names.

## Layout

- Entries (thin stubs, event handlers only): `Biotak Trigger TH3.mq4` (Full),
  `Biotak Trigger TH3 Lite.mq4` (Lite, `#define BUILD_LITE` inside it).
- All logic: `Biotak/*.mqh`, layered bottom-up, composed in the entries via
  `Biotak/EventHandlers.mqh`. A module may only depend on modules below it;
  includes at top only; every `.mqh` include-guarded.
- Settings: `Biotak/RuntimeSettings.mqh` is the single owner (mirrors,
  `#define inpX gX`, seeding, `OV_*` persistence). Seed via
  `RuntimeSettingsInit()` first in `OnInitHandler`; never read `inpX` in a seed
  below the `#define`s (silent no-op). `FF_` enum addresses never renumber.
- Indicator-wide state: `Biotak/GlobalVariables.mqh`. Panel-editable state:
  `RuntimeSettings.mqh`, not GlobalVariables.
- Trade-plan math: `Biotak/TradePlanFormulas.mqh` only. Icons: `Files/Icons/*.bmp`,
  generated by `node tools/gen-th3-icons.js`, embedded via `#resource`.

## Build (Windows)

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File compile-th3.ps1 -Project all
powershell -NoProfile -ExecutionPolicy Bypass -File compile-th3.ps1 -SourceFile ".\Biotak Trigger TH3 Lite.mq4"
```

Success = `Result: 0 errors` in `build-logs/`. Never compile `.mqh` directly.
After BMP changes: recompile, then remove & re-add the indicator in MT4
(icons load only at attach). Full deploy: `powershell -File tools/deploy.ps1`.
Linux: `./compile-th3-linux.sh all` (isolated Wine prefix, terminal stays open).

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File compile-th3.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File compile-th3.ps1 -SourceFile ".\Biotak Trigger TH3 Lite.mq4"
Get-ChildItem *.mq4 | ForEach-Object { powershell -NoProfile -ExecutionPolicy Bypass -File compile-th3.ps1 -SourceFile $_.FullName }

python tools/probe-budget-audit.py --selftest
python tools/write-budget-audit.py --selftest
python tools/gesture-budget-audit.py --selftest
python tools/zorder-audit.py --selftest
python tools/ui-text-audit.py --selftest
python tools/chart-label-audit.py --selftest

python tools/base-count-audit.py --selftest
python tools/panel-mt4-sim.py --audit
node tools/submenu_geometry_check.js
```

All must be green, and **every `.mq4` must compile**: Lite is a second entry that
includes the domain half but not the UI half, so a shared module that calls a UI
function compiles green in Full and breaks Lite (P-BUILD-01 — six `error 168`
sites shipped that way once). `probe-budget-audit`'s `lite-wall` check guards the
same rule statically; the compiles are the real gate. The root harnesses
(`Biotak_*_Test.mq4`, `Biotak ATR Audit.mq4`, `Biotak Sync Compare.mq4`) mirror
the entry's include chain by hand — a module added to the entry and not to them
breaks them silently, which is why they are compiled here too (P-BUILD-02).
`panel_mt4_sim.html` / `panel_mt4_sim*.png` /
`panel_art_proof.html` regenerate on audit runs and are gitignored.

## Working rules

- `git status` first; never edit on a dirty tree without approval. One user
  request = one commit (`feat(scope): …`; `feat!:` when removing behavior).
  Never commit uncompiled work, mixed topics, `.ex4`, or `build-logs/`.
- Comments carry `P-XX-NN` trap IDs and `-OFF` markers (e.g. `PANELDRAG-OFF`,
  `BKCURSOR-OFF`, `BKMAGNET2-OFF`, `TH3TOOL-OFF`, `VIEWLOCK-OFF`,
  `STEPOVERRIDE-OFF`). `-OFF` = retired in place: restore by uncommenting the
  marked sites and re-teaching the named gate, never by rewriting.
- Perf law: never write a chart property you would not change (MT4 repaints on
  every `ObjectSet*`); teardown/show-hide are bulk operations; every saver
  writes through a shadow and only one `GlobalVariablesFlush` exists.
- MT4 facts that bite: `OBJECT_DRAG` carries no trusted cursor (read live
  anchors); a motionless press/release emits no `MOUSE_MOVE` (gestures need a
  poll shadow); `id=1` is `OBJECT_CLICK`; writing a natively-dragged object
  cancels its drag; icons/`ex4` load only at attach.
- This file is the only `.md` in the repo. Keep it that way; research docs
  stay outside. Full history (superseded details, old `AGENTS.md`/`LEARNING.md`)
  is in git log and the outside-repo backup, not in this file.
