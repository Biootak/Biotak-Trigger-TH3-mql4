۱THE RULE

نوع گره از یک عدد می‌آید: ارتفاع باکس

نوع، از سه ATR ساخته می‌شود که همه در یک کندل خوانده می‌شوند — کندلِ خودِ باکس (anchor):

trig = ATR( nodeTF ) pat = ATR( nodeTF +1 ) str = ATR( nodeTF +2 ) h = (top − bot) / pipSize FTR : h ≤ √(trig · pat) ← مرز، وسطِ نسبتی دو ATR است نه خودِ ATR ETR : h ≤ √(pat · str) CTR : h ≤ str OTR : h > str ← این تنها مرزِ سخت است (بخش ۵)

دو مرز اول نسبتی وسط‌چین‌اند (√(a·b)، نه (a+b)/2) تا باکسی که یک مو بالا/پایین یک ATR است، نوعش با یک تیک عوض نشود (P-BK-76 P-BK-128). صفر یا ناشناخته ⇒ NONE — نوع ادعا نمی‌شود. کد: BaseKnot_Nodes.mqh (BaseKnotNodeKindOfLength)، باندها برای متن‌ها: BaseKnotNodeBandFtrEtr / …BandEtrCtr.

نردبان TF: M1 → M5 → M15 → H1 → H4 → D1 → W1 → MN — «M30» در این نردبان نیست (BaseKnot_Nodes.mqh:135-146). پس «یک پله بالاتر» از M15 می‌شود H1، و از M5 با دو پله می‌شود H1، با سه پله H4.
