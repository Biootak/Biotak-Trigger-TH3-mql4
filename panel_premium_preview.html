پیش‌نمایش پنل TRex پریمیوم — سه مسیر

هر سه نسخه در اندازهٔ واقعی MT4 کشیده شده‌اند (کارت ۳۱۲px · هدر ۵۶ · هر ردیف ۴۲ · فوتر ۴۸) و روی چارت تیره و روشن نمایش داده می‌شوند تا انتخاب روی هر دو پس‌زمینه سنجیده شود. ردیف‌ها همان ردیف‌های واقعی کارت «ATR LABELS» هستند (COUNTDOWN / COUNT COLOR / COUNT SIZE / COUNT GAP / ATR BLOCK / ROW GAP) — هیچ ردیفی اضافه یا حذف نشده. اجرا با اسکین BMP + مستطیل + لیبل MT4 انجام می‌شود؛ گرادیان، گردی گوشه، هیرلاین طلایی، واکنش پرس و سوییچ‌ها همه داخل BMP پخته می‌شوند (همان مسیر tools/gen-th3-icons.js).
با دکمه‌های بالای صفحه تم‌ها را عوض کنید — به‌صورت پیش‌فرض اُبسیدین گلد (A) فعال است؛ «همه · مقایسه» هر چهار نسخه را کنار هم نشان می‌دهد.

چه چیزی سر جای خودش می‌ماند (مهم)

  • هندسه قفل است: کارت 312 · هدر 56 · ردیف 42 · فوتر 48 · مارجین 14 — هیچ مختصاتی جابه‌جا نمی‌شود، پس هیت‌تست‌ها و درگ‌ها سالم می‌مانند.
  • هر ۱۴ کارت + پاپاور دراپ‌داون + پالت رنگ + استریپ Base Box + منوی شعاعی با یک زبان واحد بازرنگ می‌شوند (همان کاری که R-PANELS و R-PANELMOD یک‌بار انجام دادند).
  • مسیر اجرا: اسکین‌های pnl_cardN.bmp / pnl_cb_*.bmp / pnl_knob.bmp بازتولید می‌شوند، PNL_CLR_* و گلیف‌های کنترل عوض می‌شوند، منطق دست‌نخورده.
  • نکات پریمیوم که هنگام پیاده‌سازی واقعاً رندر می‌شوند: گرادیان و گردی گوشه و هیرلاین و بافت (داخل BMP) · هالهٔ حول عنصر فعال (داخل BMP) · پرس/هاور (BMP دوم) · اعداد tabular (فونت Arial Bold + چیپ مستطیلی). هیچ افکت CSS‌مانندی که MT4 ندارد وعده داده نشده.
