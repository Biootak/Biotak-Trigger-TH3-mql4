اُبسیدین گلد پریمیوم v2 — نسخهٔ نهایی

بازنویسی کامل از صفر: یک سیستم طراحی مکتوب برای همهٔ پنل‌های TRex، با المان‌های تازه، چیدمان شبکه‌ای و پالت رنگی کامل. هندسه قفل است — کارت 312 · هدر 56 · ردیف 42 · فوتر 48 · مارجین 14 — پس ارتفاع هر کارت همیشه 56 + 42n + 48 است و هیچ هیت‌تستی جابه‌جا نمی‌شود. هر افکت این صفحه (گرادیان، گردی گوشه، هیرلاین، بافت، هاله، پرس/هاور، سایه) داخل BMP پخته می‌شود؛ هیچ افکت CSS-مانندی که MT4 ندارد وعده داده نشده.
۶ خانوادهٔ رنگی ۱۶ المان کنترل ۶ حالت تعاملی شبکهٔ ۴۲px ۳ پس‌زمینهٔ چارت BMP-baked بدون ریفکتور بعدی
بزرگ‌نمایی: پس‌زمینهٔ چارت: پالت فعال:
۱

کارت پرچم — ATR LABELS

REAL ROWS · LOCKED GRID

همان ردیف‌های واقعی کارت (COUNTDOWN / COUNT COLOR / COUNT SIZE / COUNT GAP / ATR BLOCK / ROW GAP) بدون اضافه و کم کردن — ولی این‌بار با سه نوار بخش، گلیف هر ردیف، چیپ مقدار، ریل کنار ردیف فعال، تیک‌های اسلایدر و نوار اطلاعات. هر نوار بخش خودش یک ردیف کامل ۴۲px است، پس 56 + 42n + 48 دست‌نخورده می‌ماند.

۲

خانوادهٔ پنل‌ها — یک زبان، پنج رنگ

ONE LANGUAGE · FIVE HUES

بدنه همیشه اُبسیدین است؛ هر خانواده فقط رنگ لهجه (accent) خودش را عوض می‌کند: نوار امضا، هیرلاین هدر، چیپ برند، سوییچ روشن، فیل اسلایدر، سگمنت فعال و دکمهٔ Done. برای رنگی‌شدن کل مجموعه فقط یک متغیر عوض می‌شود، نه بازطراحی.

۳

گالری المان‌ها — همهٔ حالت‌ها

EVERY WIDGET · EVERY STATE

هر کنترل در حالت‌های خاموش / روشن / هاور / پرس / غیرفعال. حالت‌های هاور و پرس یک BMP دوم هستند (همان الگوی اسکین‌های حلقهٔ شعاعی)، نه انیمیشن CSS. داخل همین صفحه می‌توانید سوییچ و سگمنت و تب را کلیک کنید.

۴

سیستم رنگ — پالت پریمیوم TRex

PALETTE · PICKER

یک پالت نام‌دار و هم‌خانواده برای همهٔ لایه‌ها (ساختار، تریگر، ATR، تارگت، بیس‌باکس، هشدار) به‌علاوهٔ پاپ‌اور انتخاب رنگ با نوار هیو، مربع اشباع، فیلد HEX و ردیف RECENT. ردیف رنگ کارت از ۶ سواچ به ۸ سواچ + دکمهٔ + رسید (۴۶ + ۸×۲۲ + ۲۲ + ۹×۴ = دقیقاً ۲۸۰، بدون سرریز).

۵

آناتومی کارت — هر چیزی سر جای خودش

ANATOMY · LOCKED GRID

سمت راست کارت نمونهٔ کامل، سمت چپ برگهٔ مشخصات: هر ردیف یک المان واقعی در اندازهٔ واقعی را نشان می‌دهد، پس هیچ نشانی روی خود المان نمی‌افتد. مختصات همه از شبکهٔ ۴۲px می‌آید و هیچ عدد جادویی تازه‌ای اضافه نشده.

۶

توکن‌های طراحی — قرارداد

DESIGN TOKENS

همین اعداد باید ۱:۱ به tools/gen-th3-icons.js و PNL_* در BiotakPanels.mqh بروند.

۷

واقعیت MT4 — چه چیزی رندر می‌شود، چه چیزی نه

HONESTY CHECK

این بخش از ریفکتور بعدی جلوگیری می‌کند: هر چه در ستون «نه» است، هرگز نباید در پریمیوم وعده داده شود.

در BMP پخته می‌شود (قابل اجرا)

  • گرادیان بدنه، هدر، دکمه، سوییچ، فیل اسلایدر
  • گردی گوشه + آلفای واقعی — ۳۲ بیت BGRA، هرگز flatten نشود (P-ICONS-01)
  • هیرلاین رنگی زیر هدر و روی ردیف بخش
  • هاله و گلو حول سوییچ روشن، فیل، سگمنت فعال، دکمهٔ Done
  • بافت (ویو کربن/نویز) داخل هدر
  • سایه در مارجین شفافِ اسکین
  • پرس / هاور به‌صورت BMP دوم و سوئیچ اسکین در زمان اجرا
  • چیپ، بج، تیک اسلایدر، ریل — مستطیل گرد + لیبل MT4

هرگز وعده نمی‌دهیم (MT4 ندارد)

  • انیمیشن و ترنزیشن — سوئیچ آنی است، مثل اسکین‌های حلقه
  • بلور واقعی — شیشه فقط با گرادیان لایه‌ای شبیه‌سازی می‌شود
  • فیلتر CSS — drop-shadow، saturate، backdrop-filter
  • فونت دلخواه — MT4 فقط Arial دارد؛ tabular با Arial Bold + چیپ
  • گلیف خارج از Windows-1252 — ▼ و ✓ و − در Arial می‌شوند ?؛ چورون و تیک باید BMP باشند (P-UI-06). × و › سالم‌اند
