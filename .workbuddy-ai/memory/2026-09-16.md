# 2026-09-16

## Feasibility study: porting Biotak Trigger TH3 (MQL4) to TradingView

Requested by user (research only, no code changed). Findings:

- Pine Script v6 has **no** event handler / mouse / keyboard / drag API. Docs
  (pine-script-docs/language/execution-model) state explicitly: no mouse clicks,
  no dragging, no keyboard, no chart-event callbacks. Scripts re-run per bar/tick
  and on reload triggers only. So the whole interaction layer is unportable:
  BiotakPanels 9315 + BaseKnotTool 5519 + EventHandlers 4237 + BiotakMenu 3534 +
  TH3Tool 1838 + RuntimeSettings 1437 = ~25.9k lines of the 57,412 total.
- Modularity: no `#include`. Only `library()` + `import user/lib/version`.
  Library must be published (public/private) first; version is explicit and
  manually bumped. Exported functions cannot touch library globals (only `const`)
  and cannot call `input.*()` -> design must be pure. Our GlobalVariables (253
  refs) has no equivalent; 296 file-IO sites have none either.
- Toolchain: official compiler = Pine Editor in browser only (cloud). No CLI, no
  .ex4 artifact, no local build. Unofficial: folknor/pine-tools (VS Code ext,
  pine-lint CLI with `--tv`, LSP, MCP) — linter, not a compiler. So
  compile-th3.ps1 / build-logs/ / the 10 python audits have no Pine equivalent;
  verification shifts to Pine Profiler + Strategy Tester + Bar Replay + log.*().
- Hard limits that matter: 500 lines/boxes/labels (100 polylines, only last 50
  shown by default), 9 tables, 64 plots, 40 unique request.security calls (64 on
  Ultimate), 5000 max_bars_back, 100k collection elements, 2 min compile,
  20/40 s execution, 500 ms per loop per bar.
- Interactive alternative: TradingView Advanced Charts (self-hosted JS lib,
  gated access, "Pine Script is not supported in the libraries"). JS API has
  crossHairMoved()/click subscriptions and createShape/createMultipointShape, so
  an HTML panel + drag is possible there — but the indicator must be rewritten in
  JS with own datafeed.
- Hybrid route: keep MT4 as the interactive control surface, TradingView for
  display + webhook alerts back to an EA.

Recommendation given: phase 1 extract a pure math spec (like TradePlanFormulas),
phase 2 ship a "TH3 Core" Pine indicator (levels/zones/table/alerts), phase 3
Advanced Charts only if real interaction is mandatory. Broker symbol vs TV
ticker mismatch must be validated numerically before trusting the port.
