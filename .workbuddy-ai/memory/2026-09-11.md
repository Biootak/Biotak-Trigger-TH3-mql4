### The real finding — the header SUBTITLE did not match the preview

`.subttl` in the preview is `overflow:hidden` inside a `flex:1 .htxt`. It lays the whole run
out at its natural width and the box **CUTS the last caption mid-word** — card 0 really
renders `● ZONE OVERLAY ● LINES LIVE` (verified on screen), card 1 `… ● STRU`, card 12 Setup
`… ● R:R + LEGS + TEMPL`.

The shipped MQL drew a caption **only if it fitted whole**, so it *dropped* the crossing
caption AND its dot. Quantified with browser metrics + the real `subLimit` formula
(`htx=56`, `subLimit=chipL-10`; 205 for the two hotkey cards, 239 keyless, 234/229 for the
2-digit `.ver` cards):

| card | preview | before | after |
|---|---|---|---|
| 0 Trigger Zones | 2 dots, tail clipped | **1 dot** | 2 dots, tail `LINES LIVE ON` |
| 1 Zones & Levels | 3 dots, tail `STRU` | **2 dots** | 3 dots, tail `STRUCTU` |
| 12 Base Box Setup | 2 dots, tail | **1 dot** | 2 dots (full) |
| 2 / 9 / 12a-b | tail clipped | no tail | tail drawn (MT4's 6pt is narrower, so a few more chars) |
| 3 / 6 / 7 / 8 / 10 / 11 | already exact | — | — |

**Fix (R-SUBFIT2)** — `Biotak/BiotakPanels.mqh` `PnlCreate()`: draw each caption that fits,
and for the first that crosses the box draw the longest whole-character PREFIX that stays
inside, then stop. Same sub-object names (`sub<sd>` / `subd<sd>`), so teardown is untouched.
Two details that were wrong before: the fit test is now the caption's OWN width (`textX+txtW`)
— NOT that plus the 5px gap to the next dot (the preview is cut by the box, not by the next
dot) — and `StringTrimRight` drops a dangling space so a clipped tail never ends on a gap.
Residual difference is font-size quantisation only (preview 8.5px + .5 tracking vs MT4
6pt=8px), never layout.

### Two proof (sim) bugs found while verifying — the proof was lying

1. `parse_item_map()` only understood `if(item==N) return "X";`, so **card 12 rendered with
   NO mark and NO subtitle** — both are tab-dependent (`if(g_BkTab==1) return "type";` …).
   Now: per-branch, take the LAST return when the branch has its own nested `if` (the tab
   default, which is what `g_BkTab==0` draws), else the FIRST, and ignore the function's
   trailing `return "";` sentinel.
2. **Commented-out branches were being parsed as live values** — `// TH3TOOL-OFF:
   if(item==5) return "TH3 Tool";` made `PnlTitleText(3)` read **"TH3 Tool"** (its block
   runs down to the next real branch, swallowing the two retired lines). The parser now
   strips `// …` before scanning.
Also mirrored the new subtitle rule in `tools/panel-mt4-sim.py` (the proof must keep
predicting the terminal).
